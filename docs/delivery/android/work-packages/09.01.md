## Exact implementation and contract authority

The accepted [Android #34 native record](01.03.md) supplies the Kotlin core,
platform Views and canonical local-store boundary. This work selects the local
interpreter alternative explicitly offered by #84. It creates no backend or
new shared wire schema. The detailed [retained profile](../../../RETAINED_SNAPSHOT_EVALUATION.md),
[diagnostic evaluator](../../../FROZEN_DIAGNOSTIC_EVALUATOR.md),
[private archive](../../../LOCAL_SNAPSHOT_ARCHIVE.md) and
[explicit draft projection](../../../DRAFT_SNAPSHOT_PROJECTION.md) remain the
source boundary descriptions.

**Preparation** accepts only a RetainedDraftSnapshot produced by the actual
archive decoder. It rechecks exact raw Build/Catalog/Ruleset/DependencyGraph and
optional Pricebook bindings, complete schema and local bounds, mathematical
identity, selection IDs and roles, item ID/version/kind, links, all eighteen
catalog-reference mappings and the existing projection admission. Duplicate
catalog IDs with ambiguous versions are explicitly unsupported; nothing chooses
first, last or latest. The graph's exact schema, identity, revision and raw hash
are required. Evaluation processes every rule and does not select or prune rules
using graph edges.

**Evaluation** is the stable synchronous SnapshotEvaluator.evaluate(request)
interface. LocalSnapshotEvaluator executes the pinned Kotlin evaluator itself;
neither arbitrary incoming report text nor caller code/metric overrides determine
the result. ReferenceReportAdapter checks the computed report's schema,
Build/catalog/rules/graph bindings, rule order/IDs/severity/affected selections,
outcomes, counters, result and readiness. The wrapper additionally checks complete
report identity, mathematical revision, fixed time, code/message/remediation,
empty finding-evidence arrays and exact computed report bytes. A structurally
consistent caller-supplied report is not proven reference execution.

**Delivery** uses PreviewSnapshotAnalysis and the existing AnalysisCoordinator,
with worker and delivery executors. The full mathematical Build identity,
complete bundle/source identity, every exact artifact/status and profile digest
participate in the actual coordinator identity. Its Long value 0 is a local
immutable-view epoch, not a narrowing of Build revision. The exact request object,
fresh opaque attempt and coordinator ticket must all match. A repeated selection
or A-to-B-to-A transition cannot revive a retired callback.

The native SnapshotEvaluationSection lists actual existing archive entries and
requires explicit selection. It displays identity, pins, fixture and observation
times, all outcome counts, independent severity and failures. Same-window/session
checks, pause, destruction and recreation retire old controls and queued results.
Archive IO and evaluation run on the worker. The viewer has no draft persistence
adapter, pending-form input, mutation, sharing or network operation. The native
directory is filesDir/retained-snapshots, outside the entire managed draft library.
No demo archive is silently created. The existing archive API supplies inputs;
creation/removal UI remains separate product integration.

The underlying source draft may legitimately have been deleted after independent
archival. A captured older index supports historical inspection only; it cannot
repair a lost head or mint current archive CAS. The logical read-only loader never
initializes a namespace or activates an empty replacement index. Ordinary
filesystem lock bookkeeping is still possible.

### Supported semantics and explicit refusals

Pass/fail/unknown/skipped and severity remain independent. False applicability
skips a rule; unknown applicability remains unknown. Boolean domination, exists
and null retain their original meaning, so absent measurements do not force every
rule to be unknown. Error/fail makes the report invalid; otherwise unknown makes
it indeterminate; otherwise it is valid within this profile. A warning/fail may
coexist with valid. Readiness remains blocked or needs_review, never universal
deployment authorization. Affected IDs are sorted active selections of affected
kinds, not a proven minimal causal set; remediation is displayed, never executed.

Every requested ResourceEstimate or CostEstimate is independently diagnosed and
withheld. Missing, malformed, foreign, wrong-hash and unsupported requested
artifacts remain distinct from NotSupplied. An unavailable artifact does not erase
another independently bound input. Even caller-declared calibrated confidence or
complete cost coverage cannot qualify an operand. An exact retained Pricebook
supplies no CostEstimate, zero cost or budget pass. Units, selected applicability,
estimator provenance, rate eligibility, arithmetic, material coverage and rights
need a separately governed evidence profile before future use.

Exact decimal strings support at most twelve fractional digits. The existing
restricted Python-compatible equality/container/set/string/pointer operations and
twenty-eight-digit VRAM arithmetic remain the declared subset. Unsupported raw
floating/exponent operands, nested unhashable sets, non-string substring operands
and non-ASCII array indices receive local unsupported outcomes when reached.
Raw integral exponent/decimal Build revision spellings such as 1e0 remain
explicitly unsupported by this interpreter although the archive correctly treats
their mathematical identity as revision 1. Valid large integer revisions remain
exact beyond Long. No frozen-schema error or value rewrite disguises these local
admission decisions. VRAM sums are accounting, not proof of pooled usable memory.

Each evaluated input is bounded at 256 KiB and 20,000 tokens, with 4,096 UTF-16
units per string, in addition to the strict reader's depth/key/number/UTF-8/
duplicate/surrogate limits.
The 250,000-operation default and 1,000,000 maximum are work budgets, not a
wall-clock timeout or a claim that every allocation is charged. Unsupported/work
limit/invalid input/binding/output/clock/engine failures and cancellation return
no partial compatible report.

The report retains the literal frozen fixture time 2026-10-16T09:00:00Z.
The separately captured observedAt comes from the local observation clock;
deterministic golden tests retain their explicitly injected synthetic time.
Neither field proves external evidence freshness. The separate proposed
android-placement-receiving/0.1 and later CD-1/CD-2/CD-11 semantics are not silently
adopted by this profile.
