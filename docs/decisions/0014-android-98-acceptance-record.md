## Decision and alternatives

the relative path. The record is the single criterion, prerequisite-intake,
failure/recovery, exact-original and receiving record for the implemented local

and hosted native evidence from its receiving history. Duplicating it would create
competing acceptance records. The narrow placement keeps them together and preserves
the original website coordinate as history. No existing website file is copied,
removed or made secondary.

the final record after effective placement. No other work-package path, shared
service, public App Link authority, contract, issue relationship, assignee or
