# Pick Your AI — Android

The Android planning client for discovering, configuring, checking, costing, comparing and sharing AI stacks. The mobile device is not automatically the inference target.

This repository currently contains contribution and scope guidance only. No application implementation, build toolchain, backend or release is included.

- [Delivery Project 4](https://github.com/orgs/Pick-Your-AI/projects/4) and program [Pick-Your-AI/pickyour.ai#34](https://github.com/Pick-Your-AI/pickyour.ai/issues/34).
- Repository and framework decision: [Pick-Your-AI/pickyour.ai#67](https://github.com/Pick-Your-AI/pickyour.ai/issues/67). Repository creation is partial progress; framework, module layout and other architecture decisions remain open.
- Shared-service decision: [Pick-Your-AI/pickyour.ai#68](https://github.com/Pick-Your-AI/pickyour.ai/issues/68); reuse canonical services rather than create a competing backend.
- [Repository scope](docs/REPOSITORY_SCOPE.md), [contributing](CONTRIBUTING.md), [agent instructions](AGENTS.md), [MIT license](LICENSE).

Use the [platform program prompt](https://github.com/Pick-Your-AI/pick-your-ai-research/blob/f297ac558fb15bdedbcf391d84b63a3a7dc38019/prompts/mobile/ANDROID.md), [shared rules](https://github.com/Pick-Your-AI/pick-your-ai-research/blob/f297ac558fb15bdedbcf391d84b63a3a7dc38019/prompts/mobile/SHARED.md), [launch instructions](https://github.com/Pick-Your-AI/pick-your-ai-research/blob/f297ac558fb15bdedbcf391d84b63a3a7dc38019/prompts/mobile/README.md), and [issue/acceptance/handoff index](https://github.com/Pick-Your-AI/pick-your-ai-research/blob/f297ac558fb15bdedbcf391d84b63a3a7dc38019/prompts/mobile/INDEX.md). These immutable links reference merged [research PR 108](https://github.com/Pick-Your-AI/pick-your-ai-research/pull/108).

Planning issues remain in `Pick-Your-AI/pickyour.ai`. Refresh live assignees, native parents, prerequisites, Project fields, active work and linked PRs before execution. Do not create duplicate tracking or controllers. Repository creation does not launch a campaign or satisfy a delivery acceptance criterion.
